01

Problem Statement

"How might we support people in discovering overlooked forms of visual media while making learning about interface evolution accessible, even for XR beginners?"

Television has evolved dramatically since the 1950s, from mechanical systems to digital smart TVs. However, most people are unaware of the rich history of TV interfaces and interaction design. This project explores how Mixed Reality can make learning about this evolution more engaging and accessible.

02

Research

We conducted comprehensive user research to understand how people interact with XR technology and what makes historical learning engaging.

7 Interviews
24 Surveys

Key Insights

  1. Users unfamiliar with XR need clear onboarding and intuitive controls
  2. Physical controls (knobs) create nostalgic connection and enhance engagement
  3. Gesture control was engaging but unreliable due to sensitivity, overlapping gestures, and insufficient feedback or guidance.
  4. Learning through interaction is more effective than static content
03

Solution

XRTV is a Mixed Reality application that lets users interact with historical television sets using both physical and gesture controls, creating an immersive learning experience.

Knob Controls

Physical ESP32-powered dials for authentic retro TV interaction

Gesture Control

Natural hand tracking for intuitive XR interaction

Learning Mode

Interactive timeline of TV evolution and interface design

MR Passthrough

Blend virtual TV with real environment for immersive experience

05

Technical Architecture

Input

ESP32 Dials

Physical I/O

Serial communication via USB

Engine

Unity Engine

+ Meta XR SDK

Core processing layer

Output

Meta Quest

MR Passthrough

Display & interaction

The system integrates physical ESP32-powered dials that communicate with Unity via serial connection, while Meta XR SDK handles hand tracking and passthrough rendering for an immersive Mixed Reality experience.

06

Results

What Worked

  • Physical knob controls enhanced user engagement
  • Passthrough MR created immersive learning environment
  • Users successfully learned about TV evolution
  • Intuitive gesture controls lowered barrier to entry

Future Improvements

  • Expand TV model library with more historical models
  • Add audio and visual feedback cues
  • Create comprehensive onboarding tutorial
  • Implement multiplayer learning experiences
